# Networking Basics - Project 0

This project covers the fundamentals of the OSI (Open Systems Interconnection) model.

## File Descriptions

- **0-OSI_model**: Answers to two questions about the OSI model.
  - Question 1: What is the OSI model? Answer: 2 (Conceptual model)
  - Question 2: How is the OSI model organized? Answer: 2 (Lowest to highest level)

## OSI Model Layers (Covered in this project)

- **Layer 4 - Transport**: TCP/UDP protocols.
- **Layer 3 - Network**: IP and ICMP protocols.
